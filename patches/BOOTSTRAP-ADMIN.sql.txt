After running supabase/khaavio-platform-admin-migration.sql:

1. Open Supabase Dashboard > Authentication > Users.
2. Find your own existing Khaavio login account and copy its user UUID.
3. Replace the placeholder below with that exact UUID and run this statement in SQL Editor:

insert into public.platform_admins (user_id)
values ('YOUR_AUTH_USER_UUID'::uuid)
on conflict (user_id) do nothing;

Do not add restaurant owners or customers to platform_admins. This is a privileged internal allowlist.
